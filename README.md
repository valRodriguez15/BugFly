# BugFly - Gestor de Incidentes Tecnológicos

**BugFly** es una plataforma orientada a la trazabilidad y gestión del flujo de trabajo de errores de software en entornos empresariales, permitiendo registrar, clasificar y realizar seguimiento al estado de cada bug reportado.

## Arquitectura y Tecnologías
La aplicación utiliza una arquitectura contenerizada para garantizar la portabilidad e integración continua:

* **Backend:** FastAPI (Python)
* **Base de Datos:** PostgreSQL 15
* **Frontend:** Next.js (TypeScript + Tailwind CSS)
* **Orquestación:** Docker & Docker Compose
